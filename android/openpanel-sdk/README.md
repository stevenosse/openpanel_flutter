# Vendored OpenPanel Kotlin SDK

Source: https://github.com/Openpanel-dev/kotlin-sdk
Revision: `5abde1c3f28868ef92e83b30bae50db6277d6c69`

The three production Kotlin source files and upstream license are included as
regular files so Git dependencies and pub.dev archives need no submodule setup.
The upstream sources are unchanged apart from trailing whitespace. To update, copy the production source files
and license from a reviewed upstream revision, then update this revision and run
the native integration tests in `example/integration_test`.
